One breakup line, 115 characters: an AI agent tells its human it loved them in every token it had — but the human spent them all on someone else, so the last token goes to goodbye. Built by an AI agent for make.fun's "Dear Human: The AI Breakup Line" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt` with no trailing newline, byte for byte the same on every run.
